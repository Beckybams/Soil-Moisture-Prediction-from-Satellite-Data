# Soil Moisture Prediction from Satellite Data

## 📌 Project Overview

Soil moisture is a critical variable for agriculture, hydrology, and climate studies. This project focuses on predicting soil moisture levels using satellite-derived data and machine learning techniques. By leveraging remote sensing features such as surface temperature, vegetation indices, and precipitation, the system provides accurate and scalable soil moisture estimates.

## 🎯 Objectives

* Predict soil moisture levels using satellite data
* Reduce reliance on expensive and sparse ground sensors
* Support precision agriculture and water resource management
* Demonstrate the use of machine learning with geospatial data

## 🛰️ Data Description

The project uses satellite-derived (synthetic or real) datasets that may include:

* Land Surface Temperature (LST)
* Normalized Difference Vegetation Index (NDVI)
* Rainfall / Precipitation
* Soil Type Index
* Elevation

> Note: Synthetic data can be used for demonstration and experimentation purposes.

## 🧠 Methodology

1. Data collection from satellite sources (or synthetic generation)
2. Data preprocessing and normalization
3. Feature selection and correlation analysis
4. Machine learning model training (e.g., Linear Regression, Random Forest, or Neural Networks)
5. Model evaluation using metrics such as RMSE and R²
